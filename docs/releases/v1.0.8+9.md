# v1.0.8+9 preview

This preview consolidates the restored tournament features and the storage-safety fixes for user testing.

## Included

- Restored dashboard, statistics, tournament results, ranking history, TV display, scheduling, and planning behavior, with regression coverage.
- Safer local-data handling: only the documented SQLite migration is applied; unknown older database versions are rejected without modifying the database.
- Tournament JSON schema 24 recovery requires an exact matching `tournaments.json.v22.bak` beside the active data file. The error message reports the expected path.
- Planning settings remain separate from tournament JSON. Settings formats 1–3 are supported; unknown formats are rejected rather than overwritten.
- Windows update-package validation and restart handling improvements.

## Important for testing

This is a preview build. Back up each device's local data before testing. Device data is not automatically merged or replaced by this release. Keep the devices' current tournament data separate until a canonical copy has been explicitly chosen.

The actual Windows in-app update flow still needs end-to-end confirmation on an installed copy. If a storage-format error appears, preserve the data files and the complete error message; do not delete or replace them.
