# Dart Tournament Manager 3.0.1+101

- Vereinheitlicht die Spielplanreihenfolge in Übersicht, Partien & Ergebnisse,
  Spielleiter-Dashboard, Zweitmonitor, Sprachausgabe und Spielplanexport.
  Dynamische Pläne folgen der Board-Planung und den Prioritätshinweisen; feste
  Pläne behalten ihre gespeicherte Reihenfolge.
- Aktualisiert die README auf den aktuellen Stand der Spielplan-, Notiz- und
  Simulationsfunktionen.
- Ermöglicht manuelle Simulationsstarts auf einem freien Board sofort, auch
  während dessen simulierter Leerstandszeit. Automatische Starts berücksichtigen
  die konfigurierte Leerstandszeit weiterhin.
