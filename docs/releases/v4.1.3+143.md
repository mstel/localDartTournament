# Dart Tournament Manager 4.1.3+143

## Live-Turnier Hotfix

- Behebt den 4.1.2+142-Regressionsfehler beim Live-Publish: `400 invalid_request / headers must have required property authorization`.
- Der direkte Multipart-Viewer-Upload übernimmt jetzt `Authorization` aus der aktuellen Supabase-Session (falls nicht in `storage.headers` vorhanden) und ergänzt `apikey` aus der Supabase-Config.
- Fehlende Anmeldung wird jetzt klar als Fehler gemeldet.

## Nach dem Update

1. App auf **4.1.3+143** installieren.
2. Sicherstellen, dass du im Verein/Supabase angemeldet bist.
3. Im Turnier einmal **Live veröffentlichen/aktualisieren** auslösen.
4. Prüfen:

   ```powershell
   curl.exe -I "https://rbcsrqisbuutnnxpmcvp.supabase.co/storage/v1/object/public/live-tournament/verein-live/index.html?channel=verein-live"
   ```

   Erwartet: `Content-Type: text/html; charset=utf-8`.
