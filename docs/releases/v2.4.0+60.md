# Dart Tournament Manager 2.4.0+60

- Verbessert die Turnier-Zeitvorschau: KO-Folgerunden rechnen mit der vollen
  möglichen Spieldistanz. Boardwechsel werden bei Liga- und
  Freundschaftsformaten sowie zwischen tatsächlich gespielten Kratzer-Runden
  berücksichtigt; unbesetzte Kratzer-Boards verlängern die Vorschau nicht.
- Beschränkt Achievement-Berechnung auf aktive Spielerkatalog-Profile, die
  der jeweiligen Rangliste zugewiesen sind. Ranglistenabhängige Player
  Insights erscheinen nur für Mitglieder einer dem Turnier zugeordneten
  Rangliste.
- Ermöglicht individuell anpassbare Achievement-Schwellwerte pro Rangliste
  mit einer Option, die Standardwerte wiederherzustellen.
- Verbessert die deutsche Audioansage im Ton-Modus durch verständlichere
  Boardnummern und eine kurze Pause vor der Ansage einer Alternativpartie.
