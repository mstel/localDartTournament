# Dart Tournament Manager 2.3.9+59

- Ergänzt Player Insights mit kompakten Spieler-Badges und ausführlichen
  Erklärungen im Tooltip. Die Anzeige lässt sich pro Turnier aktivieren und
  erscheint im Zweitmonitor.
- Ergänzt einen optionalen, pro Turnier gespeicherten Ton-Modus. Nach
  erfolgreich gespeicherten Ergebnissen über „Leitung“ ertönt ein lokaler
  Signalton; anschließend werden die aktuelle nächste Partie und, falls
  vorhanden, eine Alternative für das freigewordene Board auf Deutsch
  vorgelesen.
