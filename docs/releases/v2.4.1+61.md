# Dart Tournament Manager 2.4.1+61

- Ergänzt globale, dauerhaft gespeicherte Ein-/Aus-Schalter für die einzelnen
  Player Insights in den Einstellungen.
- Fasst gleiche Insight-Kategorien bei einer Partie zu einem Badge zusammen;
  der Tooltip nennt beide betroffenen Spieler. Es werden höchstens drei
  Kategorien angezeigt.
- Lässt Unstoppable Momentum und Hot Streak bei einer laufenden Serie von
  mindestens fünf Siegen ersetzen.
- Sortiert Achievement-Ranglisten im Spielerprofil in derselben Reihenfolge
  wie die Ranglistenübersicht.
- Wertet nachträglich im Challonge-Archiv erfasste Bestleistungen für
  rückwirkende Ranglisten-Achievements aus.
- Veröffentlicht Achievement-Level, XP und Fortschritte je aktivierter
  Rangliste in der neuen Website-API-Ressource
  `?version=2&resource=achievements`.
