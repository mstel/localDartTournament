# Dart Tournament Manager 2.1.3+37

- Ergänzt einen vollständigen Spielplan mit Ergebnissen und einen
  K.-o.-Baum im Vollbild für Dashboard und zweiten Monitor.
- Ergänzt Setzungs-, Freilos-, Sieger-, Ausscheidungs- und verbleibende-Leben-
  Hinweise sowie kompakte Match-Zusammenfassungen und Bestleistungen.
- Ergänzt vier Gruppenverteilungen: Zufall, ausgeglichene Gruppen,
  Stärkestufen bündeln und manuelle Verteilung mit Drag-and-drop.
- Ermöglicht das vorausgefüllte Bearbeiten einer Turnierkonfiguration mit der
  Wahl zwischen Aktualisieren und Anlegen einer bereinigten Kopie. Ergebnisse
  werden beim Aktualisieren geschützt.
- Ergänzt konfigurierbare Turnierhinweise, eine neue Tie-Breaker-
  Standardreihenfolge und gemeinsame Standings-Berechnung für Turnieransicht
  und zweiten Monitor.
- Ergänzt lokale Supabase-Anmeldediagnosen für Windows inklusive App- und
  Systemversion, Projekt-Host sowie DNS-/HTTPS-Prüfungen. Zugangsdaten,
  API-Schlüssel und Sitzungstoken werden nicht protokolliert.
- Lässt den Windows-Release-Build den konfigurierten Supabase-Key gegen das
  Projekt prüfen. Dies verhindert bekannte Build-Konfigurationsfehler, ist
  aber keine Garantie, dass gerätespezifische Anmeldeprobleme behoben sind.
- Reduziert den Datenverkehr der Website-Turnierliste durch einen kompakten
  Index und Seiten mit jeweils zehn abgeschlossenen Turnieren. Konten ohne
  veröffentlichten Index bleiben durch einen Rückfall auf das bisherige
  Datenmodell kompatibel.
- Stabilisiert die serialisierte Warteschlange für lokale Speicherzugriffe,
  damit nach asynchronen Abläufen weitere Speicherungen zuverlässig fortgesetzt
  werden.
