# Dart Tournament Manager 2.7.6+96

- Scopes live achievement updates to the metrics that can change for the current
  event: first participation, a played match, recorded best performances, or
  tournament completion.
- Keeps completed achievement values stable during ordinary result entry and
  skips loading monthly performance data when the current update does not use it.
- Leaves monthly performance achievements and completed-ranking awards out of
  match news.
- Caches group standings until tournament data is saved, reducing duplicate
  standings calculations during result-page rebuilds.
- Adds profile-mode timeline spans for run-page, result-list, director-dashboard,
  group-standings, timing, and archive-save work.

Achievement history still receives a full refresh after corrections and other
operations that can change past results. The profile trace from the test system
showed no frame above one second; confirm the result-entry latency on the target
device after installing this release.
