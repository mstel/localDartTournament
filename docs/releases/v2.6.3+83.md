# Dart Tournament Manager 2.6.3+83

- Achievement-Anforderungen aktualisieren ihre Beschreibung direkt beim
  Bearbeiten. Angepasste Alternativwerte werden auch für die Berechnung
  verwendet und im Website-Read-Model veröffentlicht.
- Ranglisten-Read-Modelle enthalten jetzt die Teilnahmegrenze sowie die
  benutzerdefinierten Achievement-Ziele und Parameter. Diese Werte werden mit
  dem lokalen Datenbank-Backup gesichert und beim manuellen Cloud-Upload an die
  Homepage übertragen.
- Insights aktiver Spieler erscheinen im Zweitmonitor nur beim Hover über die
  Spielernamen. Die alternative Zahlenwertspeicherung wird nur im aktivierten
  Sprachassistenz-Modus angeboten.
- Die Startseiten-Infokarten wechseln im Abstand von fünf Sekunden.
- Das Wiederöffnen und Zurücksetzen später Etappen begrenzt die
  Fortschrittsneuberechnung auf die betroffenen und folgenden Etappen. Die
  Etappenaktionen sind auch im Turnierleiter-Modus verfügbar.

Das SQLite-Schema bleibt unverändert. Das Website-Read-Model wird additiv
erweitert; bestehende Felder und die Schema-Version bleiben kompatibel.
