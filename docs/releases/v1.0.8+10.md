# v1.0.8+10 preview

This corrective preview fixes a Windows startup blocker in v1.0.8+9.

## Fix

The backup service now maps each local store to its correct file, including the
schema-22 proof backup. Previously the file map was incomplete and mismatched,
so app startup stopped before any restore recovery ran.

The startup error now includes a safe diagnostic cause and the recovery
transaction directory when one exists. The fix does not delete, replace, or
merge local data.

## Testing note

Keep the separate backup of each device's `%APPDATA%\DartTournamentManager`
folder. To test the Windows preview without overwriting the previous app
folder, extract the new ZIP into a separate folder and launch its executable.
If startup still fails, preserve the full error message and the local files.
