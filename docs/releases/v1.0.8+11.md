# v1.0.8+11 preview

This corrective preview addresses schema-24 data blocked by a missing
account-scoped v22 proof file.

When an old local workspace is copied into an account-scoped directory, its
adjacent `tournaments.json.v22.bak` now moves with the tournament file. If an
account workspace already exists, the app copies a legacy proof only if its
contents exactly match the current schema-24 tournament document, ignoring
only `schemaVersion`. Existing proof files are never overwritten, and a
mismatched proof is never copied.

This version does not merge devices or choose a different tournament dataset.
Keep the separate device backups. If the app still reports a missing proof,
do not copy the small root proof beside the larger account tournament file.

The local reset flow now takes a byte-for-byte verified snapshot before
clearing active stores, leaves existing backups and account metadata intact,
and pauses automatic cloud synchronization. A fresh local dataset remains on
this device until the user explicitly confirms that it should replace the
account's cloud snapshot.
