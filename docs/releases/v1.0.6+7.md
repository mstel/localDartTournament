# Dart Tournament Manager v1.0.6+7

## Fehlerbehebung: Schema-24-Turnierdaten

- Stellt die Unterstützung für Turnierspeicher-Schema 24 wieder her.
  `v1.0.3+3` schrieb dieses Format; `v1.0.4+4` senkte die akzeptierte
  Versionsgrenze ohne eine JSON-Datenmigration.
- Erhält den in den Schema-24-Datensätzen explizit gespeicherten
  `countsForRanking`-Wert.
- Benötigt für Schema 24 keine `.v22.bak` aus einem anderen Speicherpfad.
  Die bestehende Datei wird beim ersten späteren Schreibvorgang als `.bak`
  gesichert.
- Unbekannte höhere Speicherversionen werden weiterhin abgelehnt, ohne die
  Quelldatei zu verändern.

## Datensicherheit und Update

- Vor dem Update die vollständige Sicherung von
  `%APPDATA%\DartTournamentManager` behalten.
- Keine App-Daten löschen und keine ältere `.bak` über aktuelle Dateien
  kopieren.
- Windows wird als ZIP-Bundle aktualisiert, nicht als MSI-Installer.
