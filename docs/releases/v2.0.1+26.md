# Dart Tournament Manager 2.0.1+26

## Authenticated read-only website API

- Publishes a versioned website read model with player names, configured
  rankings and standings, player statistics, best performances and completed
  tournaments.
- Keeps the existing full-workspace backup unchanged and publishes the
  separate snapshot in the authenticated account's private Storage folder.
- Adds the `website-read-model` Supabase Edge Function. It requires a valid
  Supabase user session, reads only the caller's RLS-protected object, and
  exposes GET only.
- Excludes unfinished and reopened tournaments. Profile birthdays, external
  service identifiers and darts setup details are not part of the player
  catalog response.
- Adds setup and server-side Astro integration guidance in
  `docs/website_supabase_api.md`. The separate Astro website project is not
  modified by this release.
