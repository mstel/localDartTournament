# Dart Tournament Manager 4.1.6+146

## Laufende Regeln

- **Falsche Sperre behoben**: Automatisch erzeugte Freilos-/Bye-Matches werden nicht mehr als gestartete Folgephase gewertet. Dadurch bleiben Regel-/Qualifikationsänderungen während der laufenden Phase möglich, solange keine echte Folgephase begonnen hat.
- **Übernehmen robuster**: Wenn eine Phase tatsächlich gesperrt ist, zeigt Übernehmen den konkreten Grund als SnackBar. Nach erfolgreichem Speichern wird der Draft sauber neu aufgebaut, damit der Button nicht in einem inkonsistenten Zustand hängen bleibt.
- **Puffer-Schutz bleibt aktiv**: 15s-Speicher-Timeout und `finally`-Reset gegen endloses Puffern.
