# v4.2.1+151

## Änderungen

- **Netzdiagramm/Leistungsprofil**: „Ranglisten-Maximum“ in „Vereinsmaximum“ umbenannt. Hover/Touch auf Datenpunkte zeigt konkrete Werte für Spieler, Vereinsdurchschnitt und Vereinsmaximum.
- **Skalierung**: Siegesrate skaliert von 50% (Mitte) bis 100% (voller Ausschlag). Bestleistungen nutzen als Vereinsmaximum `ceil(Vereinsdurchschnitt) * 2` (mindestens 1); Werte darüber bleiben am vollen Ausschlag.
- **Spielerprofil**: Performance (gesamt) ohne Siegesrate-Kachel. Reihenfolge: Performance (gesamt), Aktuelle Form, Bestleistungen, Errungenschaften, Performance Statistiken im Detail. Netzdiagramm liegt in den Performance Statistiken im Detail unter „Performance-Entwicklung“ und über dem Scoring-Graph; Jahresauswahl steuert Zeitraum/Daten des Netzdiagramms. Ohne Daten im Zeitraum wird nur der Vereinsdurchschnitt angezeigt.
- **Teilnehmervergleich**: Dieselbe Netzdiagramm-Logik/Tooltips/Skalierung.
- **Website-Read-Model/API**: `playerSpider` enthält zusätzlich `clubMax`; `rankingMax` bleibt abwärtskompatibel als Alias.

## Technische Hinweise

- `PlayerSpiderComparison.toJson()` exportiert `clubMax` und weiterhin `rankingMax`.
- Keine Schema-Migration nötig.
