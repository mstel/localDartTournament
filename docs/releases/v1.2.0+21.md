# Dart Tournament Manager 1.2.0+21

## Group draw and tie-breakers

- Persists wheel draws as completed and uses the saved slot order to build the
  groups shown in tournament settings.
- Rejects invalid stored group draws instead of silently assigning participants
  in their original order.
- Allows the tie-breaker order to be changed for the active group stage while a
  tournament is running. Results tables and advancement forecasts use that
  order.

## Tournament corrections

- Adds an **Einstellungen** menu to completed tournament results with the
  **Turnier erneut öffnen** action.
- Reopened tournaments retain settings and match results, resume with the
  clock paused, and can be completed again after corrections.
- Aligns the stage match-count preview background with the regular surface.

The tournament archive schema advances to version 28. Existing archives are
read as before; the normal versioned backup is created when an older archive is
first saved.
