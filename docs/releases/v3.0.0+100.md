# Dart Tournament Manager 3.0.0+100

- Randomisierte Simulationsdauern variieren jetzt sekundengenau zwischen den
  konfigurierten Minutenwerten (einschließlich der Grenzwerte).
- Nach einem Simulationsschritt können Partien auf bereits freien Boards
  ausgewählt und gestartet werden, auch wenn andere Boards noch belegt sind.
- Der Simulations-Log verwendet nun den normalen Oberflächenhintergrund.
