# Dart Tournament Manager 2.6.1+81

- Achievement-Fortschrittsanzeigen verwenden nun auch für abgeschlossene
  Erfolge ein grünes Häkchen. Die Texte der Platzierungs-Achievements nennen
  jetzt ausdrücklich „Platz X oder höher“.
- Monatsbezogene Achievements bleiben erfüllt, sobald die Bedingung in einem
  Monat des Ranglistenzeitraums erfüllt war. Dafür werden aufgezeichnete und
  importierte Monatsstatistiken gemeinsam ausgewertet und bestehende
  Berechnungsergebnisse neu berechnet.
- Die Elo-Entwicklung eines Spielers ordnet Turniere chronologisch auf einer
  Januar-bis-Dezember-Achse ein. Turniernamen erscheinen im Tooltip statt als
  dauerhafte Liste unter der Grafik.
- Das Jahresfeld der Performance-Statistik hat nun ein separates, lesbares
  Label. Das zusätzliche Detailfeld unter der Performance-Grafik entfällt;
  die Informationen bleiben im Tooltip verfügbar.

Dieses Update ändert weder das SQLite-Schema noch das Website-Read-Model.
Lokale Turnier-, Spieler- und Statistikdaten werden nicht gelöscht oder
migriert.
