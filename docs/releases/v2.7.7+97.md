# Dart Tournament Manager 2.7.7+97

- Adds a persisted fixed-play-order mode and a fixed tournament schedule for
  director mode, including drag-and-drop reordering, promote/defer actions,
  manual position changes, and explicit schedule recalculation.
- Adds a team comparison to league and friendly-match views, second-screen
  standard layouts, result summaries, and completion exports. Ranking sections
  are omitted for these team matches.
- Adds configurable schedule PDF fields, page orientation, and a tournament-name
  based PDF filename.
- Adds a setting to disable the dynamic home dashboard and configure its card
  rotation interval.
- Keeps the creation participant count aligned with selected participants and
  pre-fills the tournament-format finder with that count.
