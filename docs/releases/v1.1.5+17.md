# Dart Tournament Manager 1.1.5+17

## Tournament comparison, dashboard, and results

- Centers comparison category labels, adds separators between players and
  categories, and removes the Elo history chart from the player comparison.
- Uses the dark blue and subtle gold palette for dashboard and second-screen
  match cards and information panels.
- Limits second-screen next-match suggestions to five when longer player names
  would otherwise require more than two lines.
- Shows only players whose ranking position changed in results and the PNG
  export. The export uses the dark blue palette, separates point gains/losses,
  and includes the expected tournament duration range.
- Keeps random group draw assignments aligned with configured group sizes.

## Tournament settings, second screen, and rankings

- Places the tournament name field and save action compactly side by side when
  the available width permits, and displays elapsed time next to the clock
  status.
- Opens and focuses the existing Windows second-screen window instead of
  spawning additional windows, and closes that window when the main app exits.
- Allows ranking administrators to name Elo tiers and configure their rating
  thresholds per ranking. Existing rankings retain the default tier bands.
- Hides self-service registration and Google sign-in; operators are created
  manually in Supabase.

No tournament database schema, migration, or backup format changes are
included.
