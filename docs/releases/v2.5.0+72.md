# Dart Tournament Manager 2.5.0+72

Diese Version wird zunächst als nicht öffentliche Testversion bereitgestellt.
Bitte vor der Installation ein aktuelles Backup der lokalen App-Daten erstellen.

- Builds on the 2.4.10+70 storage baseline, retaining tournament schema 38 and
  local database schema 13 compatibility while adding monthly-statistics import
  data as database schema 14.
- Imports historical monthly player aggregates from Excel without inventing
  individual matches; checkout values remain empty when the source has none.
- Improves board scheduling, board reassignment, match seeding, and the live
  match display on the second screen.
- Preserves Challonge double-elimination results when archived pairings differ
  from the locally reconstructed bracket.
- Includes the 2.5.0 tournament, statistics, and presentation improvements from
  the prior feature build.
