# Dart Tournament Manager 1.2.3+24

## Random draw

- Replaces the tournament-creation draw wheel with random group distribution.
- Adds a standalone draw wheel under **Werkzeuge & Verwaltung**, with editable
  group names, manual or even assignment, text copy, and PNG export.

## Govee ambience

- Stores the Govee API key on the device for reuse after restarting the app.
- Adds tournament ambience controls for cold white, red, green, yellow, cyan,
  and supported rainbow scenes.
- Includes devices that advertise a rainbow scene even when they do not offer
  RGB or color-temperature controls.

## Desktop and second screen

- Moves the second-screen explanation into a compact help action.
- Launches the Windows updater through its saved PowerShell restart script,
  using explicit script encoding and execution policy.
