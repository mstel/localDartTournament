# Dart Tournament Manager 1.1.4+16

## Tournament results and statistics

- Replaces the player comparison Elo graph with a three-column comparison
  table: one player on each side and the category in the center.
- Shows named ranking-position changes, including movement up/down and
  unchanged or unavailable positions.
- Adds a portrait PNG export from completed tournament results with the
  tournament summary, podium, Elo and ranking-position changes, league moves
  when applicable, and named best performances.
- Adds an expected-duration estimate and range to the tournament results.

## Tournament display and group draw

- Aligns dashboard and second-screen match-card colors with their display
  settings and animates rotating next-match suggestions.
- Limits the second-screen latest-results area to two fully visible cards;
  additional results remain available by scrolling.
- Uses the configured group sizes and persists the exact random group
  assignments.

## Desktop updates and account sign-in

- Reports desktop update activation failures with a persistent diagnostic and
  the path to the detailed restart log; successful activation clears stale
  failure markers.
- Configures app callback redirects for account registration, Google sign-in,
  and password-reset requests.
- Requires a non-empty Supabase publishable key when building the Windows
  release package.

Google OAuth still requires enabling and configuring the provider and
redirect allowlist in the Supabase project. Email confirmation and password
reset delivery require server-side email/SMTP configuration.

No tournament database schema, migration, or backup format changes are
included. The installed `v1.1.3+15` Windows executable's update-and-relaunch
path was not available for end-to-end verification.
