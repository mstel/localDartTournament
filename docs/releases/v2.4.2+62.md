# Dart Tournament Manager 2.4.2+62

- Hält Achievement-Beschreibungen bei ranglistenspezifisch angepassten
  Zielwerten synchron, auch im Formular während der Bearbeitung.
- Zeigt Ranglisten-Auszeichnungen als gemeinsame Kategorie mit einem möglichen
  Abschluss an (0/1 oder 1/1), statt die vier nicht gleichzeitig erreichbaren
  Auszeichnungen zu einem irreführenden X/4-Zähler zu addieren.
- Ergänzt unter **Einstellungen → Werkzeuge & Verwaltung → Ton Modus
  Einstellungen** globale Namensstandards für Ansagen: vollständiger Name oder
  Vorname plus Nachnamensinitial. Ein vorhandener Spitzname kann Vorrang
  erhalten.
