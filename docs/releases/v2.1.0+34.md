# Dart Tournament Manager 2.1.0+34

- Verbindet neue Builds mit dem neuen App-Supabase-Projekt.
- Stellt den Supabase-Workspace-Abgleich auf manuelle Bedienung um. Lokale
  Änderungen werden nicht mehr automatisch in die Cloud geladen und beim
  Starten, Fortsetzen oder Anmelden werden keine Cloud-Backups heruntergeladen.
- Ermöglicht die Übertragung eines lokalen `.dartbackup` in das neue Projekt:
  Backup lokal wiederherstellen und anschließend „Lokalen Stand hochladen“.
- Vermeidet einen doppelten Download bei der Bestätigung einer
  Cloud-Wiederherstellung.
