# Dart Tournament Manager 4.2.0+150

## Spiderdiagramm / Spielerstatistiken

- Neues 5-Kategorien-Spiderdiagramm für Spieler: `Scoring`, `Average`, `Checkout%`, `Bestleistungen`, `Siegesrate`.
- Skala pro Kategorie: Außenkante = höchster Wert des stärksten Spielers im Ranking; Mitte = Durchschnitt aller dem Verein zugeordneten Spieler; farbige Fläche = aktueller Spieler.
- Spielerprofil: Spiderdiagramm oberhalb von „Performance Statistiken im Detail“.
- Statistiken → Teilnehmer vergleichen: zwei Spiderdiagramme links/rechts unter den direkten Begegnungen; Teilnehmervergleich aller Ranglisten und direkte Begegnungen bleiben darunter erhalten.

## Website-Read-Model / Homepage

- App-Read-Model liefert `playerSpider` pro Spieler inkl. Spielerwerten, Vereinsdurchschnitt und Ranking-Maximum.
- `playerSpider` ist in den v2-Ressourcen `statistics` und `performance` enthalten, damit die Homepage aktuelle Daten ohne zusätzliches Rechnen aus bestehenden Feldern ableiten muss.
- Homepage Intern (darts.tv-1927.de): Spielerprofil und Vergleichsseite rendern das Spiderdiagramm; API-Validierung/Fallback übernimmt `playerSpider`.
