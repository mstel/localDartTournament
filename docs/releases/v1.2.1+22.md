# Dart Tournament Manager 1.2.1+22

## Tie-breakers

- Uses the configured tie-breaker order of the final group stage when
  calculating completed tournament placements and the podium.
- Moves live tie-breaker configuration into a dedicated **Tie Breaker
  Einstellungen** panel. Changes are applied explicitly, persisted together
  with the runtime stage, and confirmed to the user.

## Group draw

- Restores accepted wheel assignments from the persisted draw order when an
  untouched group stage is reopened, without showing the draw again.
- Keeps subsequent manual group-position changes in the saved draw order.
