# Dart Tournament Manager 2.0.0+25

## Standalone draw wheel

- Removes each selected player from the wheel immediately after the draw.
- Locks the player list and group count once the first draw begins.
- Displays groups A onward with fixed placeholder slots and fills each group
  from top to bottom before continuing to the next group.
- Shows the wheel and group setup side by side on wide screens; narrow layouts
  stack the same content vertically.
- Removes manual group reassignment. Text and image exports continue to show
  the final draw order.
