# Dart Tournament Manager 1.1.6+18

## Second screen and tournament results

- Keeps second-screen match cards visible when notices appear, uses available
  width more effectively, and arranges recent results in a compact responsive
  two-column layout.
- Shows progress by tournament stage, with group match counts beside each
  group, and uses the blue-and-gold progress palette.
- Shows the ranking name once above ranking changes and arranges the three
  ranking-change summaries side by side in the results view and PNG export.

## Player names and group draws

- Adds separate first- and last-name fields to player profiles. Player lists
  and tournament selection use the full name; match cards prefer a nickname or
  show the first name with the last-name initial. Completed tournament results
  retain the full tournament player name.
- Prevents a preliminary random allocation from changing the group assignment
  produced by the draw wheel.

## Automatic synchronization

- Resumes a paused automatic sync only when an account is signed in and a valid
  local tournament archive contains data.
- Queues a follow-up sync request when another request arrives while a sync is
  already running.

This release updates the tournament archive and local SQLite schema. Existing
archives and databases are migrated while retaining their existing player and
tournament data. Automatic account synchronization was not tested against a
production account.
